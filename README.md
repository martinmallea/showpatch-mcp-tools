# ShowPatch · MCP Tools

Puente de automatización entre inteligencia artificial y consolas de
iluminación profesional (grandMA3 / ChamSys MagicQ).

## ¿Qué resuelve?

- Parchear robótica china clonada sin manuales.
- Adaptar geométricamente un show a un escenario distinto en minutos.
- Traducir la intención de un show de MA a ChamSys en caliente.

ShowPatch expone estas tareas como herramientas MCP consumibles por
un LLM, que razona sobre el rig y aplica cambios en caliente.
